# Week 4 — Capstone UI

Streaming chat with visible tool steps.

```bash
# Terminal 1 — from repo root
npm run w4:server

# Terminal 2
npm run w4:ui
```

Open http://localhost:5173 — `/chat` is proxied to Hono on :3001.

**Paths:** `client/` = React, `server/` = Hono SSE API.
